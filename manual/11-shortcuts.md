# 11. Keyboard Shortcuts

## ⌨️ Overview

The SMEDI SME Database includes comprehensive keyboard shortcuts to improve efficiency and speed up daily tasks. This section covers all available shortcuts organized by functionality and context.

##  Global Shortcuts (Suggested)

These shortcuts work throughout the entire application:

### Navigation
| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl + H` | Go Home | Navigate to dashboard |
| `Ctrl + G` | Go To | Open "Go To" search dialog |
| `Ctrl + K` | Search | Open global search |
| `Ctrl + ,` | Settings | Open user settings |
| `Ctrl + ?` | Help | Open help documentation |
| `Alt + M` | Menu Toggle | Show/hide main navigation menu |

### Common Actions
| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl + S` | Save | Save current form or data |
| `Ctrl + N` | New | Create new record |
| `Ctrl + E` | Edit | Edit current record |
| `Ctrl + D` | Delete | Delete current record |
| `Ctrl + R` | Refresh | Refresh current page |
| `Ctrl + P` | Print | Print current page/report |

### System
| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl + Alt + L` | Logout | Log out of the system |
| `F5` | Refresh | Reload current page |
| `F11` | Fullscreen | Toggle fullscreen mode |
| `Esc` | Cancel | Close dialogs or cancel operations |

### Most Common Shortcuts
```
Navigation:     Ctrl + H (Home), Ctrl + K (Search)
```

```
Cancel:         Esc (Cancel operation)

Refresh:        F5 (Reload page)
Help:           Ctrl + ? (Get help)
```

## 💡 Tips for Efficient Use

### Learning Shortcuts
1. **Start with basics**: Learn global navigation shortcuts first
2. **Practice daily**: Use shortcuts instead of mouse when possible
3. **Print reference**: Keep a printed shortcut reference nearby
4. **Muscle memory**: Consistent use builds automatic responses

### Customization
1. **Browser shortcuts**: Some shortcuts may conflict with browser shortcuts
2. **Accessibility**: Shortcuts work with screen readers and accessibility tools
3. **Mobile adaptation**: Touch gestures complement keyboard shortcuts
4. **Regional differences**: Some shortcuts may vary by keyboard layout

### Troubleshooting
1. **Conflicts**: If shortcuts don't work, check for browser extension conflicts
2. **Context sensitivity**: Some shortcuts only work in specific contexts
3. **Permissions**: Some shortcuts require appropriate user permissions
4. **Focus**: Ensure correct element has keyboard focus
